# T1 外部数据集接入计划

这些压缩包来自 DCU 光合开发社区，适合做开发阶段的补充实验。它们不是湖南大学赛题的官方评测集，不能替代组委会提供的 `baseline.py`、正确性集或计分脚本。

## 优先级

| 数据集 | 用途 | 接入方式 | 优先级 |
| --- | --- | --- | --- |
| LongBench | 长上下文预填充、KV Cache 和 decode 吞吐 | 先选一个子集，统一转成 `generation` JSONL | P0 |
| HelloBench | 长对话/开放问答，检查长输入下输出稳定性 | 转成 `generation` JSONL；清单字段保留在 metadata | P0 |
| SuperGLUE-AX | 逻辑蕴含分类和答案抽取 | 转成 `classification` JSONL | P1 |
| MMLU-Pro | 多选知识与推理，测试答案抽取 | parquet 读取后转成 `multiple_choice` JSONL | P1 |
| tau2-telecom | 多轮工具调用和 Agent 成功率 | 独立 Agent runner；不能直接交给普通 `generate` | P2 |

统一记录格式为：

```json
{"id":"...","dataset":"...","prompt":"...","reference":null,"task_type":"generation","metadata":{}}
```

`reference` 可以是字符串、答案列表或分类标签。`metadata` 保留原数据集的语言、类别、评测清单和任务状态，避免把原始字段误当成模型指令。

## 本地盘点

```bash
python scripts/inspect_datasets.py /path/to/dataset_staging \
  --output dataset_inventory/report.json
```

该命令只读取 JSON/JSONL 的结构和少量样本，不会修改原始数据。

## 转换样本

```bash
python scripts/convert_datasets.py /path/to/dataset_staging longbench \
  --limit 32 --output dataset_inventory/longbench.sample.jsonl
python scripts/convert_datasets.py /path/to/dataset_staging hellobench \
  --limit 32 --output dataset_inventory/hellobench.sample.jsonl
python scripts/convert_datasets.py /path/to/dataset_staging ax \
  --limit 128 --output dataset_inventory/ax.sample.jsonl
python scripts/convert_datasets.py /path/to/dataset_staging mmlu_pro \
  --limit 128 --output dataset_inventory/mmlu_pro.sample.jsonl
python scripts/convert_datasets.py /path/to/dataset_staging tau2_telecom \
  --limit 2 --output dataset_inventory/tau2.sample.jsonl
```

MMLU-Pro 转换需要 `pyarrow`。如果当前环境没有它，在 Notebook 中安装与镜像 Python/torch 兼容的版本，或直接使用 DCU 光合环境预装的数据读取库。

## DCU Notebook 建议顺序

1. 先用 LongBench 的 `multifieldqa_en` 或 `multifieldqa_zh` 取 16--32 条，确认 tokenizer、上下文长度和显存峰值。
2. 用 HelloBench 取 16 条，记录输入 token、输出 token、吞吐；它的 checklist 适合后处理评估，第一阶段只做生成和人工抽检。
3. 接入 AX 和 MMLU-Pro 的固定小样本，添加 `entailment/not_entailment` 与 `A/B/C/D/E` 抽取器，再比较准确率。
4. 最后单独实现 tau2-telecom 的 tool schema、状态转移和成功率评估。不要把 `main_policy.md` 或 workflow 文档复制进普通提示词。
5. 每次实验记录模型目录、commit、镜像/DTK/PyTorch 版本、dtype、attention、batch、上下文长度、重复次数和正确性结果。

原始压缩包、模型权重、缓存和完整转换结果不提交 Git；仓库只提交脚本、字段说明和少量不敏感样本。
